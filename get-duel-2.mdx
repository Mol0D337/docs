---
title: "GET /duel/{id}"
---

Retrieve a prediction by its ID for the authenticated user. Returns the prediction details and the list of players. Requires authentication.

### **Parameters**

| Name | Type | Header | Path | Required | Description |
| :-- | :-- | :-- | :-- | :-- | :-- |
| Authorization | string | Authorization | — | yes | Authorization<br />Bearer token |
| id | string | — | id | yes | Prediction ID |
