---
title: "Create a prediction"
---

### Step 1 — Open the dashboard

Log in to the DuelDuck admin dashboard using your API Owner account.

To create a new prediction, click the New Prediction button in the dashboard header or open the Active Duels page and start a new prediction from there.

### Step 2 — Configure the prediction

Fill in the required prediction information:

- prediction question;
- voting deadline;
- currency;
- pricing model;
- fee settings;
- image.

The prediction question should clearly describe a future event with an objectively verifiable outcome.

### Step 3 — Publish the prediction

After creation, the prediction becomes active and immediately becomes available through the API for integration into your frontend platform.

All active predictions are displayed in the Active Duels table until their deadline expires.

Prediction management, voting state tracking, and blockchain interactions are handled automatically through the DuelDuck backend infrastructure and Solana smart contracts.
