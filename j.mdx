---
title: "GET /duel/public/{id}"
---

**URL:** https://xapi.duelduck.com/duel/public/{id}

Retrieve a prediction by its ID without requiring authentication. Returns the prediction details if found.

### **Parameters**

| Name | Type | Path | Required | Description |
| :-- | :-- | :-- | :-- | :-- |
| id | string | id | yes | Prediction ID |

### **Responses**

**Response content type:** application / json .
