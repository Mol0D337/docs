---
title: "Duel Duck Prediction API"
---

The DuelDuck Prediction API is a backend infrastructure solution designed for platforms that want to integrate blockchain-based prediction markets into their products. It provides a complete set of tools required to create, manage, resolve, and monetize predictions through a simple API integration.

The system is powered by Solana smart contracts, enabling fully on-chain execution with low transaction fees and automatic reward distribution. All user funds and voting actions are processed directly through connected crypto wallets in a non-custodial environment.

With the API, **platform owners can:**

- create and manage prediction markets;
- allow users to participate using crypto wallets;
- configure prediction parameters such as deadlines, currencies, vote pricing, and fees;
- monetize user participation through configurable commission fees;
- track prediction analytics and earnings through the dashboard.

The API is designed to minimize operational complexity. Most processes — including vote recording, pool calculations, and reward payouts — are fully automated. Platform owners only need to create predictions and resolve outcomes once events are completed.

### Pricing model

Creating an account and generating API keys is completely free. There are no setup costs, subscription fees, or monthly platform charges.

Instead, DuelDuck operates on a revenue-sharing model based on the commission income generated through your prediction markets.

**Revenue share tiers:**

- 0% — if monthly commission revenue is below \$1,000;
- 25% — for revenue between \$1,000 and \$10,000;
- 20% — for revenue between \$10,001 and \$50,000;
- 15% — for revenue between \$50,001 and \$100,000;
- 10% — for revenue above \$100,000.

This means you only pay when your platform generates revenue, making the API accessible for both small projects and large-scale platforms.

### Revenue and fee mechanics

Each prediction can include a configurable fee between 1% and 10%. This fee is deducted from the losing side’s pool during reward distribution and transferred to the prediction creator as revenue.

Users always pay exactly the amount they stake when voting. Rewards are calculated automatically after platform fees are applied.

Platform owners can track accumulated earnings through the dashboard and claim profits on a monthly basis.
